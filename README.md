# Data Analytics Portfolio

Product and customer analytics projects in SQL and Python, using e-commerce data.

## Projects

### [GA4 Ecommerce Funnel Analysis](https://github.com/Apzsara/Data-Analytics-Portfolio/tree/main/ga4-ecommerce-funnel-analysis)
BigQuery, Python. Funnel, RFM and behavior analysis of 4.3M GA4 events from the Google Merchandise Store.

### [Online Retail Customer & Revenue Analysis](https://github.com/Apzsara/Data-Analytics-Portfolio/tree/main/online-retail-customer-analytics)
DuckDB, Python. RFM segmentation, CLV by segment and monthly cohort retention on 1M+ retail transactions.

### [E-Commerce Operational Analytics](https://github.com/Apzsara/Data-Analytics-Portfolio/tree/main/ecommerce-operational-analytics)
DuckDB, Python. Delivery performance and review behavior across 100K+ Olist orders.

## Tools
SQL (BigQuery, DuckDB), Python (Pandas, Matplotlib)
